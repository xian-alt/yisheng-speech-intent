# 颐声：700条护理需求录音（MP4版）
本目录提供700条护理需求语音录音。根据项目负责人确认，录音通过ESP32-S3采集并上传，以MP4音频文件提供，与论文测试数据编号一一对应。

原始格式、文件哈希和处理记录仍保留在索引及参数文件中，方便追溯
## 文件

- `audio/`：700条MP4录音，编号`utt-0001`至`utt-0700`。
- `audio_index.csv`：录音编号、参与者代号、参考标签、MP4路径与SHA-256，以及原WebM文件的路径、SHA-256和编码参数。
- `conversion_settings.json`：转码参数、原始压缩包哈希和检查结果。

`audio_path`指向本包MP4；`source_audio_path`相对于原WebM包，原WebM文件不重复放入本包。用`utterance_id`连接公开数据库，即可找到转写、参考标签和模型预测。

两名志愿者各350条；七类各100条，每人每类50条。本包不包含其他历史录音、私人业务数据库、姓名、联系方式或本机路径。项目负责人于2026年10月27日确认已取得两名参与者公开原始声音、允许他人下载和收听的许可。其他再利用条件请联系仓库负责人。
