# 基础模型与LoRA：分类延迟、显存及重复推理

本目录对应论文第41版的表4及第5.3节。数据来自2026年11月2日在RTX 5060 Laptop GPU上的实际运行，不改写原SQLite中的历史预测或参考标签。

## 表4：700条ASR转写上的分类资源测量

| 方法 | 延迟中位数（ms） | P95（ms） | 峰值CUDA allocated（GiB） |
|---|---:|---:|---:|
| 基础模型（零样本） | 142.34 | 263.12 | 0.956 |
| LoRA模型 | 181.96 | 312.80 | 0.976 |

- batch=1；基础权重float16；贪心解码，不采样；最多生成16个新token；输入截取前500字符；CPU线程4。
- 每种方法在单独Python进程运行，预热20次。LoRA为论文原检查点，适配器未合并到基础权重。
- 延迟覆盖700条ASR文本的无缓存调用。计时前后执行CUDA同步，包含分词、模型生成、解码和标签解析，不包含ASR、模型加载或写盘。
- 峰值显存覆盖ASR和校对文本两种条件的整个评估阶段，包含模型权重。allocated是当前PyTorch进程的张量分配峰值；reserved是分配器保留峰值，两者分开保存。这里不是整张显卡的总占用，也不是整个系统的内存。
- 校对文本的相同输入可以复用同一模型的预测，相关行标记`cache_reused=true`，其延迟置为null，不参与延迟汇总；全部录音仍逐条计分。

## 固定检查点的三轮重复推理

同一75条开发文本顺序运行三轮，每轮重新推理，不使用缓存，共225次调用。

| 方法 | 三轮每轮平均延迟的均值（ms） | 样本标准差（ms） | 与首轮预测不一致次数 |
|---|---:|---:|---:|
| 基础模型 | 168.32 | 22.95 | 0 |
| LoRA模型 | 229.64 | 11.48 | 0 |

两种模型各自的三轮预测完全一致。这里描述固定检查点下的重复推理，不是不同随机种子独立训练的性能波动。700条ASR延迟的中位数/P95与三轮开发集平均延迟的均值/标准差，使用不同样本和统计口径，不应互换。

## 记录文件

`base/`与`lora/`分别包含：

| 文件 | 内容 |
|---|---|
| `configuration.json` | 运行环境、检查点/数据/提示词/包装器哈希及测量范围 |
| `predictions.jsonl` | 700条ASR及700条校对文本的逐条预测；ASR行保留计时 |
| `metrics.json` | 两种转写条件的总体、逐类、混淆与SOS指标 |
| `asr_resources.json` | 700条无缓存ASR调用的延迟统计；显存峰值覆盖两种文本条件 |
| `development_latency.jsonl` | 75条开发文本三轮逐次推理结果和计时，共225行 |
| `development_resources.json` | 开发集重复推理、延迟统计与该阶段显存峰值 |

`summary.json`汇总上述两个模型的结果。逐条预测与原`compact_regression/base`、`compact_regression/v21`归档一致，两种文本条件下均没有预测差异。

提示词文件原始SHA-256为`58498965d1121d2734d6c285dc68385adb725a8e938d58ca989fba83427de711`。配置中的`prompt_sha256`针对Python以UTF-8文本模式读取、规范化CRLF后的实际运行字符串，因此与原始文件字节哈希不同。配置中的`script_sha256`是原本地测量运行器的历史哈希，不是下述归档复算脚本的哈希。

## 复算与核验

在仓库的程序目录`yisheng-speech-intent/`运行，仅需Python标准库，不需要模型或GPU：

```powershell
python scripts/reproduce_llm_resources.py
python -m unittest discover -s tests -p test_llm_resources.py -v
```

复算脚本检查数据/提示词/包装器哈希、1400条预测的唯一ID和参考标签、分类指标与原归档的一致性、700条无缓存ASR计时、三轮开发集计时及重复预测。显存峰值保留原运行记录；离线复算不会重新测量GPU显存。

## 评估边界

这些录音曾用于开发阶段错误分析，因此结果属于同批录音上的开发阶段回归评估，而非新采集独立测试。资源测量只覆盖分类阶段，不代表端到端语音系统耗时。本轮没有开展多种子重复训练或全量微调比较。
